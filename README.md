# AI-Agents-Presentations

A public location for presentations I am giving on agents. This repository is organized to hold presentations along with their associated media assets (images, videos, and PDFs).

## Repository Structure

```
AI-Agents-Presentations/
├── presentations/      # Individual folders for each presentation
├── images/            # Image assets used in presentations
├── videos/            # Video assets used in presentations
└── pdfs/              # PDF documents and slides
```

## How to Use This Repository

### For Viewing Presentations

Browse the [presentations](#presentations) section below to find summaries and links to materials for each presentation.

### For Contributors

When adding a new presentation:

1. **Create a presentation folder**: Create a new folder in `/presentations/` named after your presentation (use kebab-case, e.g., `intro-to-ai-agents`)
2. **Add your materials**: 
   - Place images in `/images/` (consider using a prefix matching your presentation name)
   - Place videos in `/videos/` (consider using a prefix matching your presentation name)
   - Place PDFs in `/pdfs/` (consider using a prefix matching your presentation name)
3. **Update this README**: Add an entry in the Presentations section below with:
   - Presentation title
   - Date and venue (if applicable)
   - Brief summary
   - Links to relevant materials
